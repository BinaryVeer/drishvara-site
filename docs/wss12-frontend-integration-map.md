# What Stars Say — frontend integration map

The existing page and live governed reflection form are preserved. The full-report workspace uses two fixed, fictional profiles generated through the existing audited report modules. It never reads form inputs or authorizes a personal forecast. Every view retains its publication/precision flags. One scenario has populated D1/D9/D10 charts; another demonstrates an actually withheld D9.

Reserved integrations: uncertainty-aware marriage/career timing, approved daily/monthly/yearly interpretation, personal colour/do-and-don't rules, and consented subscriber profile storage. No fabricated dates, advice, preferences or forecasts fill these slots.

Presentation: retained navy/gold identity and existing photographs/advertising rails; readable Arial report text; focused chart selector; horizontally scrollable accessible tabs on mobile; one methodology area rather than repeated explanation panels/links. Optional journal remains collapsed. Existing name requirement, location search, language switching, request privacy, source bindings and server controller remain unchanged.

Generate with `node scripts/build-wss-report-demo.mjs`. The public diagram asset is generated byte-for-byte from the canonical audited diagram module. Test data gates with `node tests/star-report-workspace.mjs`; browser QA visits every section at1440/390/320px in English/Hindi, both precision scenarios and populated charts. Source URLs are unique within the methodology panel. Demo dates and values are fixed; they are not refreshed as if they were current personalised advice.


## Matching and dated Life Themes

Kundali Matching has its own tab with two read-only synthetic profiles, their birth/precision bases, an unassigned score and proposed alignment labels. There is no verified matching engine in the repository: method, component scores, denominator, exceptions and thresholds remain unassigned. No personal intake is enabled. Future personal comparison requires both people's consent and method-specific input qualification. A withheld divisional chart is not by itself a negative compatibility result.

Life Themes and Transit Data share one Year/Month/Day selection and date key. Available demo dates:21/22November2026; monthsNovember/December2026; years2026/2027. Each context is generated through existing audited snapshot/period modules. Selecting a date changes the actual snapshots and period counts. Theme-specific descriptive paragraphs distinguish natal background, selected-period observations and the still-unqualified support assessment. No year/month/day score, favourable/adverse label or event window is inferred. Theme selection exposes career, relationships, education, resources, family and growth in one focused reading area. Unsupported dates are rejected; a required withheld natal/divisional basis remains withheld.
